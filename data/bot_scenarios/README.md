# Кнопкові сценарії бота

Редагуйте `menu.toml`, якщо треба змінити назви кнопок, порядок, вкладеність або посилання.

Редагуйте файли в `texts/`, якщо треба змінити текст, який бот показує після натискання кнопки.

Після зміни файлів перезапустіть застосунок, щоб бот перечитав сценарії.

Для фото-презентерів покладіть картинку в `media/` і в потрібному розділі `menu.toml` додайте:

```toml
content_photo = "media/example.jpg"
```

Якщо в розділі є і `content_text`, і `content_photo`, бот покаже фото з текстом як підписом.

`children` відповідає за вкладені кнопки. Наприклад:

```toml
children = ["outbound_workshops", "birthdays"]
```

`links` відповідає за кнопки-посилання:

```toml
links = [
  { title = "Сайт", url = "https://berryland.com.ua" },
]
```
